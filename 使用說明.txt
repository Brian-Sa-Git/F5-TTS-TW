【v1.0.2 合成資料夾歸位修正】
修正 Basic TTS 使用「段落素材庫」音訊時，
Gradio 可能把參考音訊複製到暫存路徑，導致程式誤以為是新的外部音訊，
因此另外建立一個新的主資料夾。

現在規則：
- 從段落素材庫套用的音訊 → 合成結果一定回到原本同一個時間主資料夾的「合成」子資料夾。
- 即使 Gradio 使用暫存複本，也會用檔名與段落編號回查原始素材位置。
- 只有 Basic TTS 真正自行上傳「工作台以外的新音訊」時，才會建立新的時間主資料夾。

例如：
2026-09-02_00-10-00_林薇英文聲音英文\
├─ 音訊\
│  └─ 林薇英文聲音英文_001_優化.wav
├─ 文字\
│  └─ 林薇英文聲音英文_001.txt
└─ 合成\
   └─ 林薇英文聲音英文_001_合成.wav


【v1.0.2 全自動裁切介面】
音訊工作台已移除：

現在統一只保留整個音檔的兩種處理方式：

2. 📦 全部自動分段＋優化

【v1.0.2 整個長音檔全部自動分段】
新增「全部自動分段」功能。

重要：
原本的「自動挑最佳 5～12 秒」只會挑一個最適合 F5-TTS 的片段。
現在另外提供：

- 📦 全部自動分段（只裁切）
- 📦 全部自動分段＋優化

這兩個功能會將整個原始音檔從頭到尾全部處理。
不論原音是 38 秒、數分鐘或更長，都會輸出所有分段，不再只有一個檔案。

分段原則：
- 優先以自然停頓作為切點。
- 一般每段盡量約 5～12 秒。
- 單一句連續超過 12 秒時，會保底每 12 秒切開。
- 不會只保留「最佳片段」，而是將所有偵測到的人聲段落全部輸出。

另新增：
- 📝 全部已裁切段落轉文字

按下後會將目前時間資料夾內所有裁切音訊逐段用 Whisper 辨識，
並在「文字」資料夾建立相同編號的文字檔。

【v1.0.2 時間分類＋段落同編號】
音訊工作台輸出方式更新：

每次上傳一個新的原始音訊，都會自動建立一個日期時間資料夾，例如：

【怎麼用】
1. 解壓縮整個資料夾。
2. 雙擊「安裝F5-TTS.bat」。
3. 選安裝位置。
4. 安裝器會自動偵測 NVIDIA 顯示卡，不固定 RTX 型號。
5. 選擇是否預先下載 E2-TTS、Whisper、Qwen 等模型。
6. 完成後桌面會建立「F5-TTS 繁中版」與「F5-TTS 微調」捷徑。

【目前包含的客製功能】
- 繁體中文介面
- 句尾停頓設定
- 英文年份安全辨識
- BCE / BC / CE / AD 大小寫辨識
- 年份範圍多種橫線辨識
- 一般英文 self-destruction / well-known 等複合字不會被年份規則誤改
- 常用隨機種子收藏，可新增、套用、刪除，重開程式仍保留
- F5-TTS / E2-TTS / Multi-Speech / Voice Chat / Finetune

【不綁定顯示卡】
安裝器不會寫死 RTX 3050、5060、5070 等型號。
它會檢查 nvidia-smi 顯示的 Driver / CUDA runtime 能力：
- 支援 CUDA 13.0 或以上：嘗試 PyTorch cu130
- 支援 CUDA 12.6～12.x：嘗試 PyTorch cu126
- 沒有 NVIDIA 或驅動太舊：先安裝 CPU 版

之後換電腦，只要重新跑安裝器，就會重新判斷。

【模型可一起攜帶】
如果你之後想把已下載模型一起帶走：
把 Hugging Face cache 放進：
portable_models\huggingface\

安裝器偵測到裡面有檔案後，會先合併到新電腦的模型資料夾，
有的模型就不用重新下載。

【自己的 GitHub】
config.json 裡有：
"custom_ui_url": ""

現在留空時，安裝器使用 payload\infer_gradio.py。
之後你把客製版 infer_gradio.py 放到自己的公開 GitHub，
可以把 custom_ui_url 改成 Raw 檔案網址。
之後安裝時就會直接從 GitHub 抓最新版，不需要重新做整包安裝器。

【重要】
- 安裝階段需要網路，除非你已經把所需程式/模型另外離線準備。
- Windows 建議使用 Windows 10/11 64-bit。
- NVIDIA GPU 加速仍需要電腦本身安裝相容的 NVIDIA Driver。
- 若公開散布，請一併遵守 F5-TTS、模型與第三方套件各自的授權條款。

【完整音訊工作台】
首頁新增「音訊工作台」。

使用流程：
1. 上傳長音檔
2. 選擇片段
3. 只裁切，或裁切並優化
4. Whisper 提取文字
5. 一鍵套用到「基本 TTS」

片段選擇：
- 自動挑最佳 5～12 秒
- 從指定開始位置找完整語句
- 從指定位置直接取 12 秒
- 手動設定開始與結束時間

裁切模式：
- 只裁切（不優化）
- 裁切並優化

裁切並優化預設處理：
- 整理頭尾長靜音
- 音量正規化
- 過濾低頻隆隆聲
- Mono / 24 kHz / 16-bit WAV
- 輕微淡入淡出，降低切點喀聲

Whisper 提取文字：
- 自動辨識
- 中文
- 英文

辨識文字可直接修改並另存 TXT。

輸出位置：
C:\AI\F5-TTS-Universal\輸出檔案
├─ 音訊
└─ 文字

頁面可直接按「開啟資料夾」快速查看輸出檔案。

注意：
「找完整語句」主要依自然停頓／靜音邊界判斷，
自動選擇後仍建議先播放確認一次。
